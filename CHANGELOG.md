# Changelog

## 0.1.0-preview.1

The first release, for Melvor Idle 2 Early Access (game version 0.11.6-alpha.1).

### Added

- Simulate every monster, dungeon and Slayer task with your setup, ranked by XP, kills and more
- Compare two setups on the same fights
- Try any gear, levels, prayers and Setup entries, owned or not
- Find the best setup for a target, with a cheaper and a safer one
- Rare drop chances per kill, and roughly when the first should drop
- Slayer masters: the best loadout for each, and which tasks to block
