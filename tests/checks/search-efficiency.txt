# A climb's steps and Droptimizer fight each set once, read at the stages below the last and stopped there when
# clearly behind the held set. At 400 trials each round is read at 100. The same search twice gives the same
# answer, and the answer opened and run gives the answer's own result.
cs2 gear GolbinForest/Golbin seed=1 trials=400 short wait=0 kinds=none lock=Cape,Amulet,Torso,Legs,RingSlot1,Gloves,Boots
expect reply "running:"
# cs2 wait fails once its 9 s pass with the search still going: sleep first, then one wait.
wait 9000
wait 9000
wait 9000
wait 9000
wait 9000
wait 9000
wait 9000
wait 9000
wait 9000
cs2 wait timeout=9
cs2 gear show
expect reply "gear GolbinForest/Golbin by xp:main, no deaths, margin 1%, seed 1"
expect reply "stage 1: 400 trials, 48 fought, 47 dropped, 1 left"
expect reply "stage 6: 400 trials, 22 fought, 21 dropped, 1 left"
expect reply "best: +5.5% [3.1, 7.8] xp:main (4,961 → 5,232 /h), stance Accurate"
expect reply "Weapon: Oak Bow → Adamant Javelin"
expect reply "hash ca26a1b42b6e"
expect reply "Weapon: Oak Bow → Maple Boomerang; stance Accurate   +4.9% [1.3, 8.4]   hash 09c2a040db4b"
