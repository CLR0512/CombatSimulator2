# A star Chk hasn't the knowledge for is refused with the game's reason and dropped while requirements are checked,
# and applies, marked, with them ignored. A change on another page is kept beside it. Every page has its data on this
# build: none is a placeholder.
cs2 open setup page=astrology side=a
cs2 side a star=DeedreeA1:on
wait 2500
cs2 ui

cs2 ui
